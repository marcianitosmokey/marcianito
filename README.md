## Importante
Todos los nombres anteriores coinciden con los nombres visibles en el repositorio del proyecto. No los cambies ni agregues espacios.

`index.html`, `estilo.css` y `script.js` deben estar en la raíz del repositorio junto con las imágenes.

### Publicar
GitHub → Settings → Pages → Build and deployment → Deploy from a branch → branch `principal` → folder `/ (root)` → Save.

### Guestbook
GitHub Pages es hosting estático. Esta versión permite elegir un alias y escribir mensajes, pero los guarda con `localStorage`: cada visitante ve sus propios mensajes. Para un muro de comentarios público y compartido hace falta conectar una base de datos/servicio externo. No se finge que el guestbook local sea compartido.

### Spotify
Las dos playlists aparecen mediante los reproductores oficiales embebidos de Spotify. Los tracks individuales se dejan como enlaces directos.

### Sonido
El navegador no permite sonido automático fiable al cargar la página. Por eso los sonidos se activan al tocar botones/elementos interactivos y tienen un interruptor `♪`.
